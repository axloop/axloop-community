## [0.1.0] - 2026-09-02

### Added

- First AxLoop Community install for Mac Apple Silicon (`darwin-arm64`), available from the [v0.1.0 release](https://github.com/axloop/axloop-community/releases/tag/v0.1.0). It ships as a tar.gz archive with an adjacent SHA-256 checksum file. No Linux or Windows build is included.

The newest install is always at the [latest release](https://github.com/axloop/axloop-community/releases/latest).
